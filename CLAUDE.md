# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

"Mr. Driver" is a top-down 2D driving game made in **Unity 6000.3.4f1** (URP 2D, new Input System, TextMesh Pro, Cinemachine). Code identifiers, comments, log messages and UI text are in Brazilian Portuguese. Keep that convention in new code.

## Building / running

No CLI build, test suite or linter is set up. You open, run and build the project in the Unity Editor (File > Build Profiles). `Assembly-CSharp.csproj` and the `.sln` files are generated by Unity. Don't edit them by hand. `Library/`, `obj/`, `Logs/`, `UserSettings/` and `.vs/` are generated too. `com.unity.test-framework` is installed, but there are no tests.

Scenes in the build, in order: `Menu`, `Tutorial` (the tutorial, opened by the TUTORIAL button), `Historia_Videogame` (the fake retro game that opens the story), `Historia_Casa`, `Historia_Autoescola`, `Historia_Exame`, `Historia_Garagem`, `Nivel1` (the first real level, the trip to the market), `Historia_Mercado` (inside the market, loaded from the middle of `Nivel1`). The five `Historia_*` scenes are generated by the Mr Driver > História menu (see below). Scene names used in code live in `ProgressoHistoria`. Scenes are loaded by name (`SceneManager.LoadScene("Menu")`), so renaming a scene breaks those calls.

## File encoding (important)

These `.cs` files are saved in **Windows-1252**, not UTF-8 (accented characters in comments and `[Header]` strings): `Scripts/Carro/` CarroController, CarteiraMotorista, Farois, LuzesFreio, LuzesRe, Nitro, PiscarAoDano, RastrosPneu, RodasDianteiras; `Scripts/Camera/CameraSegue`, `Scripts/HUD/CarteiraUI`, `Scripts/Menu/menuPrincipal`, `Scripts/Niveis/Buraco`, `Scripts/Trafego/CarroTrafego`, `Scripts/Tutorial/TutorialInicio` and the two in `Scripts/Antigos/`. Every other script is UTF-8. The Edit/Write tools refuse Windows-1252 files. Edit them in a way that keeps their encoding (for example `iconv`/`sed` via Bash), or ask the user before converting them to UTF-8. Don't let accented characters get corrupted.

## Folder layout

- `Assets/Scripts/`: runtime code by subject — `Carro` (player car and its add-ons), `Camera`, `HUD`, `Trafego`, `Pedestres`, `Poderes`, `Loja`, `Niveis`, `Tutorial`, `Menu`, `Historia`, `Garagem`, `Som`, `Videogame`, and `Antigos` (unused legacy scripts kept for reference).
- `Assets/Editor~/` (**currently disabled**): the Mr Driver menu tools. The folder name ends in `~`, so Unity ignores it: it isn't compiled and the Mr Driver menu doesn't show up. The folder's own meta is kept inside it as `Editor.meta`. To turn the tools back on, follow `Assets/Editor~/LEIA-ME.md` (rename the folder back to `Assets/Editor` and move `Editor.meta` back to `Assets/Editor.meta`). All paths below that say `Editor/...` refer to this folder. Contents — `Arte` (procedural pixel art: `PixelArt`, `HistoriaArte*`, `CidadeArte*`, `AutoescolaArte`, `MenuArte`, `RebeldesArte`), `Historia` (`MontarHistoria*`, `MontarVideogame`, `HistoriaTextos`), `Sons`, `Menu`, `Fase` (level setup: traffic, pedestrians, minimap, HUD, cars, powers...), and `ArteHistoria/` (character .txt art, path hard-coded in `HistoriaArte.PastaArte`).
- `docs/COMO_FUNCIONA.md`: a Portuguese explanation of every system, for people learning from the project.

## Architecture

Scripts live in two places: `Assets/` (car parts and effects) and `Assets/Scripts/` (controller, UI and tutorial flow). No namespaces and no asmdefs, so everything compiles into `Assembly-CSharp`. Wiring happens in the Inspector through `[SerializeField]` references and `UnityEvent`s, not in code. Many scripts check their required fields in `Start()`, then `Debug.LogError` and `enabled = false` if any is missing.

**Player car (`Assets/Prefabs/CarroNissan_0.prefab`).** Used in both levels.
- `Scripts/Carro/CarroController.cs` is the core. It does kinematic arcade physics on a `Rigidbody2D` through `MovePosition`/`MoveRotation`, with its own drift/grip model. It reads the keyboard directly: WASD/arrows, Space for the handbrake. Forward is `transform.up`. Other components never move the car themselves. They read its public state (`VelocidadeAtual`, `VelocidadeComSinal`, `EstaDerrapando`, `Acelerando`, `Freando`, `Volante`, `FreioDeMaoAtivo`) or change it through hooks: `ReduzirVelocidade`/`AbsorverBatida`, `MultiplicadorVelocidade`/`MultiplicadorAceleracao`, `ForcarAcelerar`.
- Add-on components on the same prefab: `Nitro` (Ctrl, uses the multipliers and `ForcarAcelerar`), `LuzesFreio`, `LuzesRe`, `Farois`, `RodasDianteiras`, `RastrosPneu`, `PiscarAoDano`.
- `CarteiraMotorista` is the "driver's license" health system: 20 points, invincibility frames, and the `aoPerderPontos(int)`/`aoSuspenderCarteira` events. It loses points when hitting a `CarroTrafego`. `Buraco` (pothole trigger) also calls `PerderPontos`. `CarteiraUI` (HUD) and `PiscarAoDano` listen to it.
- `Scripts/Antigos/` holds unused legacy code: `VeiculoJogador` (older force-based controller, legacy `Input`, forward is `transform.right`), `CameraSegueCarro` and `Teste`. The camera in use is `Scripts/Camera/CameraSegue` on `Main Camera.prefab`.

**Traffic (`Scripts/Trafego/`).** `RedeTrafego` is a road graph: child `PontoTrafego` nodes sit in the middle of the road, and `ligacoes` are two-way streets. `GrafoTrafego` is the runtime graph plus `Cruzamento`, which decides whose turn it is at an intersection. `GeradorTrafego` spawns the `Assets/Prefabs/CarroTrafegoVariado.prefab` cars at level start, then keeps the city busy around the player: cars farther than `raioAtivo` or stuck for `tempoMaximoParado` (off screen) are re-placed (`CarroTrafego.Iniciar` again) on a lane in a ring around the player, always outside the camera view. Cars only brake for pedestrians that are crossing (`Pedestre.NaRua`); pedestrians wait until moving cars are far enough to brake calmly. `Cruzamento.Combina` lets non-crossing movements share an intersection (same direction, opposite straight/right turns, right turns that don't target the same exit lane). `CarroTrafego` (Windows-1252) drives in the right lane. It plans a path of Bézier turns, follows the car ahead and stops for pedestrians and the player. It still supports the old `rota` loops. `AparenciaCarro` picks the model and color and runs the brake lights and turn signals. `Editor/Fase/MontarTrafego.cs` (menu Mr Driver > Trânsito) detects roads from the Tilemap (tile names containing "Rua"/"Faixa"), draws the pixel-art models and builds the prefab.

**Minimap (`Scripts/HUD/Minimapa.cs`).** A GTA-style radar for any level. It lives in `Assets/Prefabs/HUDMinimapa.prefab`, built by `Editor/Fase/MontarMinimapa.cs` (menu Mr Driver > Minimapa). At level start a temporary camera photographs the static scenery once. Cars, pedestrians, rigidbodies, UI and non-sprite renderers are hidden only for that camera, via `RenderPipelineManager.beginCameraRendering`. The photo is then stylized: road/sidewalk/grass come from Tilemap tile names, and houses are sprites whose name contains "casa". The radar rotates with `Camera.main` and clamps its view to the level bounds. `LinhaUI` draws the GPS route. The radar hides when `Time.timeScale == 0`.

**Game flow is driven by `Time.timeScale` plus UI panels.**
- `TutorialInicio` (cena Tutorial) is a step machine on `etapa` (0–9). It pauses the game (`timeScale = 0`) to show a speech-bubble panel and resumes when the matching key is pressed. The trigger volumes `GatilhoTutorialEsquerda`/`Direita`/`Cones` move it forward by calling `MostrarCurva*`/`MostrarAvisoCones`, which only work in the expected `etapa`.
- `ConeObstaculo` shows `pnlGameOver`. `ChegadaTutorial` finishes the level when the car's collider sits fully inside its box and stays stopped for 1 s. Both freeze time.
- `PauseController` (Esc) won't pause while another panel is open, or while `timeScale` is already 0. If you add a new panel that freezes time, register it there.
- Anything that loads a scene has to set `Time.timeScale = 1f` first.

**Menu (`Menu.unity`).** `MenuController` switches between the panels. `MenuPrincipal` (file `menuPrincipal.cs`) is an older menu script, and its `Jogar()` is still a stub. `VolumesJogo` maps sliders to the `VolumeMusica`/`VolumeSFX` parameters of `Assets/MixerMrDriver.mixer` (in dB) and saves them in `PlayerPrefs`.

**Input.** Active Input Handling is set to "Both". Scripts read `Keyboard.current` inside `#if ENABLE_INPUT_SYSTEM`, with legacy `Input` in the `#else` branch. Keep both branches when adding input.

**Story (`Scripts/Historia/`, editor tool `Editor/Historia/MontarHistoria*.cs`, menu Mr Driver > História).** Flow: menu JOGAR → `Historia_Videogame` → `Historia_Casa` → `Historia_Autoescola` → `Historia_Exame` → `Historia_Garagem` → `Nivel1` (drive to the market) → `Historia_Mercado` → `Nivel1` again (drive home with the rebels). The game is made for a school in partnership with Nissan: the family car (the original `CarroNissan_0` drawing, model id `Kicks`) is the father's new Nissan Kicks, and the dialogue highlights its technology. Don't bring back the old "Princesa" name. `MenuController.Jogar()` resumes at `ProgressoHistoria.ProximaCena()` until `HistoriaConcluida`, then opens the level list (button 1 = `Historia_Casa`, button 2 = `Nivel1` which needs `Historia_Garagem`). `CarteiraTirada` = exam done, `HistoriaConcluida` = garage chapter done.
- `Historia_Videogame` (plot twist, `Scripts/Videogame/`, tool `Editor/Historia/MontarVideogame.cs` = História step 0, art in `Editor/Arte/HistoriaArteVideogame.cs`): "TURBO RACER 3000 (C) 1987 MEGASOFT", a deliberately crude endless straight-road dodging game made entirely of UI on a 160x120 virtual screen (scaled 8.4x) with CRT effects and a faint reflection of Jason's face. `TurboRacer` runs title → fake loading (bar freezes) → game (speed/spawn ramp, lane changers without blinker, 2-lane trucks, wrong-way waves; never blocks all 3 lanes) → explosion → GAME OVER + "INSIRA UMA FICHA" countdown ("SEM FICHAS!" on Enter). In story mode it captures the screen (`Videogame.GuardarTela`), sets `Videogame.VeioDoVideogame` and loads `Historia_Casa`, where `RoteiroCasa.SairDaTV` shrinks that image into the bedroom TV (`ObjetoTurbo`, cell 7,2; Jason starts on the puff at 7,3) before Jason complains. `ProgressoHistoria.ProximaCena()` returns it until `Historia_Casa` is done; level button 1 opens it via `BotaoNivel.cenaParaAbrir`. After `Nivel1` is completed (`Videogame.Desbloqueado`) it is also a minigame in the Níveis screen (`AlternarMinijogo`, `Videogame.ModoMinijogo`; record in PlayerPrefs, the fake "TONHÃO 99999" stays on top). Text uses `TextoPixel` + `FontePixel` (glyph sprites baked from the game's 5x5 font).
- `Historia_Casa` is a Pokémon-style grid scene built entirely by the tool: one background sprite plus furniture sprites, `MapaCasa` (collision grid, cell (x, y) = world (x, -y)), `MovimentoGrade` + `AnimadorPersonagem` for walking characters, `JogadorCasa` (input), `NpcHistoria`/`ObjetoFala`/`PortaCasa` (all `Interagivel`), and `RoteiroCasa` (script of the scene). Sorting order is `100 + row * 10` (+5 for characters).
- `Historia_Autoescola` (the second tutorial) is built from scratch by `MontarHistoriaAutoescola.cs`: one big painted yard sprite from `AutoescolaArte` (all layout rects live there, 1 unit = 8 px), static colliders with `ObstaculoAutoescola`, physics cones with `ConeAutoescola` (they count a fault and slide back), the car/camera/HUD prefabs, and a `MissaoExame` configured via `DefinirFinal` (no license card, next scene `Historia_Exame`). `PontoExame.Orientacao` enforces reverse/parallel parking.
- `Historia_Exame` (final exam) is a copy of `Nivel1`. The tool disables its `ChegadaNivel`, reduces traffic, and places `PontoExame` checkpoints along the `RedeTrafego` graph. `MissaoExame` runs the instructor's script, counts crashes as faults, and shows `TelaCarteira` at the end. Re-running step 3 recreates it from `Nivel1`.
- The house plan (`HistoriaArte.PlantaCasa`) includes a garage (`g` floor, `G` door from the living room, `T` roll-up gate). `CriarCasa(1)` builds `Historia_Casa` (garage locked, car under a tarp, `RoteiroCasa`); `CriarCasa(2)` builds `Historia_Garagem` (`RoteiroGaragem`: parents celebrate the license, free roam, the father opens the garage and teaches the car screen, the mother asks for the market, exit through the gate → `Nivel1`). Both roteiros derive from `RoteiroBase`, which `NpcHistoria`/`PortaCasa`/`ObjetoFala`/`VitrineCarro` call. `PortaCasa` can be an exit or just a passage and can carry its own locked-door lines.
- Garage cars (`Scripts/Garagem/`, `Editor/Fase/MontarCarros.cs`): `CatalogoCarros` asset (`Assets/Historia/CatalogoCarros.asset`) holds the models (the original car split into a paintable grayscale body + details, plus the paintable traffic models) and the paint colors; `GaragemJogador` saves the choice in PlayerPrefs; `VisualCarroJogador` (installed on `CarroNissan_0`, children `VisualLataria`/`VisualDetalhes`) draws the chosen car in every scene; `TelaGaragem` is the picker UI; `VitrineCarro` is the car parked in the house garage.
- `Historia_Mercado` (`MontarHistoriaMercado.cs`, art in `HistoriaArteMercado.cs`): same grid engine as the house (`HistoriaArte` keeps the current plan in `planta`; `DesenharFundo`/`DesenharFundoMercado` set it). `RoteiroMercado`: shopping list items are `ObjetoRoteiro` shelves (id + lines + bobbing sparkle, routed to `RoteiroBase.InteragirCom`), the cashier Jussara mentions the future parts shop "Turbo Peças", then the Gangue do Escapamento (Turbo + 2 henchmen, inactive NPCs that walk in through the door) knocks over the can pyramid and leaves. Leaving sets `MissaoMercado.VoltandoDoMercado = true` and loads `Nivel1`. New characters: `Atendente.txt`, `RebeldeChefe.txt`, `Rebelde.txt` (the two henchmen are `Rebelde` with palette swaps via `CriarPersonagem(..., salvarComo, trocas)`).
- Rebels on the map (`Scripts/Trafego/CarroRebelde.cs`, `GangueRebelde.cs`, art in `Editor/Arte/RebeldesArte.cs`): kinematic vehicles (graffiti cars made from the traffic models, and motorcycles) that wander the `RedeTrafego` graph ignoring every rule (speeding, no stopping, wrong-way overtaking, zig-zag motos). They take license points themselves on collision (`CarteiraMotorista` only reacts to `CarroTrafego`) and show as red dots on the minimap (`CarroRebelde.Todos`).
- `Nivel1` story: `Editor/Historia/MontarHistoriaNivel1.cs` adds everything under the `HistoriaNivel1` object (Jason's house art from `CidadeArte` on the lot at the end of the dead-end street, the market building above the parking lot, lot paint, trees, and `Missao` with `MissaoMercado` + `CanvasHistoria` + arrow). `MissaoMercado` implements `IFinalNivel` (`AntesDaTela(ChegadaNivel)`), which `ChegadaNivel` runs before completing the level; on the way there it calls `chegada.Interromper()` and loads `Historia_Mercado` instead. On the way back (`VoltandoDoMercado`) it moves the car to the market spot, moves the `ChegadaNivel` to the front of Jason's house and calls `GangueRebelde.Soltar()`; the flag stays on until the level is finished, so a restart resumes the way back. `CriarExame` deletes `HistoriaNivel1/Missao` from its copy. The same tool also replaces the old neighbor house images (children of the root `Casas` object, Casa1..Casa4 JPGs) with procedural pixel-art lots from `Editor/Arte/CidadeArteCasas.cs` (`CidadeArte.Vizinhanca`, partial class of `CidadeArte`): it reads each old sprite's world rect and rotation (180° = street above), clips overlapping lots, creates `HistoriaNivel1/Cenario/CasasVizinhas` and only deactivates the old objects.
- `CaixaDialogo` (typewriter dialog with portrait and beep voice) and `ObjetivoHUD` live on `CanvasHistoria`. `CaixaDialogo.AlgumaAberta` and `TelaCarteira.Aberta` block `PauseController`. `TransicaoTela` is a self-creating fade used for story scene loads.
- Character pixel art is text in `Editor/ArteHistoria/*.txt` (palette + 16x13 heads; bodies shared in `Corpos.txt`; 32x32 portraits drawn as the left half and mirrored). All dialogue text is in `Editor/Historia/HistoriaTextos.cs`. Re-running the tool overwrites edits made in the scenes' Inspector.

**Main menu tiles (`Scripts/Menu/`, `Editor/Menu/MontarMenuBlocos.cs`, menu Mr Driver > Menu).** The tool switches `PnlMenu`'s CanvasScaler to 1920x1080, hides the old `Btn*` buttons, and builds centered `BlocoMenu` tiles that copy only the old buttons' sound calls and then call the `MenuController` method. `MenuBlocos` keeps a tile selected for keyboard navigation and fills the footer description.

**Menu screens (`Editor/Menu/MontarMenuTelas.cs`, art in `Editor/Arte/MenuArte.cs`, menu Mr Driver > Menu > Montar telas do menu).** Rebuilds PnlSobre, PnlConfiguracoes (`MenuController.PnlTeste`), PnlNiveis and PnlLoja in the tile style: everything new goes under each panel's `Tela` child (deleted and recreated on re-run); old image-text elements are only hidden; the working parts (ScrollNiveis, ScrollItens, TxtMoedas) are moved/restyled. Runtime: `TelaMenu` (on the panel: slide-in, ESC/Backspace = back, keeps a selection, footer text), `SelecaoTela` (hover/select feedback + description), `OpcoesMenu` (volume %, fullscreen, restart story with double-press confirm); `BlocoMenu` also reports to `TelaMenu`. The tool rewires `VolumesJogo` to the new sliders. Both menu tools run in História > Fazer tudo.

**Sound (`Scripts/Som/`, generator in `Editor/Sons/SintetizadorSons.cs` + `Editor/Sons/CompositorMusicas.cs`, tool `Editor/Sons/MontarSons.cs`, menu Mr Driver > Sons > Gerar sons e músicas, also run by História > Fazer tudo).** All effects and the chiptune music are synthesized by code into `Assets/Audios/Gerados/` (.wav) and listed in `Assets/Resources/BancoSons.asset` (id → clip/volume, scene → music, chase music, jingles; Inspector edits survive re-runs). `Sons` (static) boots itself via `RuntimeInitializeOnLoadMethod`: it creates the persistent `SistemaSom` (pooled 2D sources + crossfading music), applies the saved volumes, plays each scene's music (chase music in `Nivel1` when `MissaoMercado.VoltandoDoMercado`), silences old scene music sources, routes group-less AudioSources to SFX, and auto-adds `SomCarro` (engine/skid/brake/reverse beep/crashes/potholes/powers, reading `CarroController` and `IPoder` state) to the player car and `SomBotao` to every Button. Gameplay code plays effects by id: `Sons.Tocar("Moeda")`, `Sons.TocarEm(id, pos)` (distance-attenuated), `Sons.TocarVinheta(...)`. The mixer's exposed params are `VolumeMusica`/`VolumeSFX` (same names as `VolumesJogo` and PlayerPrefs). The Menu and Tutorial keep their original mp3 songs.

`Assets/_Recovery/` contains Unity auto-recovered scenes, not real content.
